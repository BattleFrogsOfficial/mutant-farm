# Mutant Farm — notes for Claude Code

Grow-and-mutate idle simulator for Roblox. Luau, synced into Studio with Rojo. One PR per milestone (see "Milestones").

**Design intent lives in `docs/DESIGN.md`; this file holds the live numbers and how the code does it.** Any rule change goes into DESIGN.md with a dated note *and* here, in the same commit.

## The one rule: the server is authoritative

- Clients send **intents only**: `Plant(slotIndex, eggId)`, `Harvest(slotIndex)`, `HarvestAll()`, `TapBoost()`, `BuyEgg(eggId, quantity)`, `BuySlot()`, `Sell(itemId)`, `SellAll()`, `ClaimDaily()`, `Rebirth()`, `SetFastHatch(on)`, `BuyPotion()`, `SkipTimers()`, `BuyUpgrade(kind)`, `ClaimGroupReward()`, `Pin(itemId, on)`, `ClaimVipGems()`, `SeenLimited(eggId)`, `BuyInstantWeather(eventId)`, `RebirthNow()`, `BuyGemUpgrade(kind)`, `SetReplant(slotIndex, on)`. Never a price, value, rarity or timestamp. Robux purchases are prompted by the client (`client/Purchase.lua`) and granted only by `MonetizationService` (`ProcessReceipt` once per PurchaseId; game passes on join and on `PromptGamePassPurchaseFinished`).
- The server re-derives everything and rejects bad arguments silently (`src/server/Util/Validate.lua`). Every remote goes through `Net.on`, which rate-limits to `Game.remoteCallsPerSecond` per player and requires a loaded profile.
- `EconomyService` is the **only** writer of `cash`/`gems`. `addCash` refuses any single amount above `Valuation.maxSingleSale` for the player's tier and logs every source/sink to Analytics.
- Growth is a **pure function of timestamps** (`src/shared/Growth.lua`). No per-frame server work. `GrowthService.settle(data, now)` advances all slots and must run before anything that changes speed (the water pad, a growth boost, passes, upgrades) or reads maturity.
- `Workspace.StreamingEnabled` is off (set in `default.project.json`): the map is small and PlotController expects every island to replicate. Client code may *preview* numbers with the shared modules (timers, sell values) but never decides outcomes.

## Conventions (follow these in every change)

- **Server-authoritative:** see above. New client actions are new intents through `Net.on` + `Validate`; the shared rule modules (`ShopRules`, `Costs`, `Valuation`, `Growth`) decide, the client only previews.
- **Config, not logic:** every balance number lives in `src/shared/Config/*.lua` (UI layout numbers too, e.g. `Config/EggShopUI.lua`). Tuning never edits services or UI code. Keep the balance tables below in sync.
- **Pink = spending only** (`Theme.colors.spend`): SHOP, Gems +, R$ and Gem buttons, bundle, 2x Luck badge. Navy for every other button, rarity colors only for rarity, red only for notification dots. Never show friction as a red error.
- **HUD below the GuiService inset:** the main ScreenGui keeps `IgnoreGuiInset = false`; nothing of ours goes into Roblox's top-bar strip (only the hatch cutscene and the dim backdrop are full screen).
- Boxy UI, no `UICorner`; only glyphs GothamBlack has; studs only on primary buttons; reuse `UI/Components.lua`.
- Pure logic goes in `src/shared` with a `tests/*.spec.luau`; keep the UI preview and the world checker at 0 issues.
- No model names in commits or code. Commit messages end with the attribution lines the session asks for.

Services/controllers are plain tables with `Init()` (no yielding, no cross-service calls) and `Start()` (may yield and use other services). Add new ones to the `order` list in `Main.*.lua`.

## Naming conventions

- Files and modules: `PascalCase.lua`. Services end in `Service`, client modules in `Controller`.
- Functions and locals: `camelCase`. Constants: `UPPER_SNAKE`.
- Config ids are PascalCase strings used everywhere as keys: eggs `Starter Swamp Lab Toxic Void Cosmic`, rarities `Common Uncommon Rare Epic Legendary`, mutations `Shiny Golden Radioactive Glitched Cosmic`, passes `Luck2x AutoHarvest GrowthSpeed2x OfflineMutations PlotSlots10 VIP`.
- Remote names are verbs (`Plant`, `BuyEgg`) client→server and nouns (`State`, `Notify`, `Harvested`) server→client.
- Analytics SKUs: `Egg_<tier>`, `Sell_<tier>_<rarity>`.

## Profile data (ProfileStore, store `PlayerData_v1`)

Template lives in `DataService.lua`. Items can carry `pinned = true`. Rules: JSON-safe only, no arrays with holes, no mixed keys, so slots and inventory are **string-keyed maps** (`slots["3"]`, `inventory["17"]`). Fields already exist for later milestones (rarity, mutations, size, pen, gems, passes, streak, codes) so no migration is ever needed; add new fields to the template and `profile:Reconcile()` fills them. Autosave every `Game.autoSaveSeconds` (120); ProfileStore flushes on BindToClose. Studio without API access falls back to a mock store automatically.

Profile watering: `wateredUntil` / `waterMult` (the growth boost running), `waterOffer` (the next tap's multiplier, rolled by the server), `onPad` (standing on the water pad; false on join and offline), `stats.waters` (taps) / `stats.padVisits`. Profile `gemUpgrades = { penSlots, luck, offline }` (Gem upgrade levels, kept through rebirth). Profile `patches[index] = { replant, egg }`: each owned patch's Auto-Harvest replant toggle and the last egg planted there (kept while the patch is empty; the snapshot carries `replant = { [index] = true }`).

Plot attributes (server -> every client, written by `PlotService.refresh` after each batched change): plot `OwnerUserId WateredUntil WaterMult OnPad Speed Pen(JSON) PenCenter PenSize`; slot part `Index State(owned|buy|locked) EggId Mutations Growth UpdatedAt Required Price`.

- Unlocks are checked in one place, `shared/ShopRules.lua` (server buy handler, shop UI, tray, simulator). "Earned" is `stats.totalCashEarned`: every Cash gain through `EconomyService.addCash` (sells, pen income, rewards); spending never lowers it.
- **Gem egg variants** (`<Tier>Gem`, generated in `Eggs.lua`): same design plus a crystal overlay, same species pool, grow time and values; rarity table = base Uncommon+ weights x2 then renormalized (a separate base table, so the 2x pass and potion still apply on top under the 6x cap). Prices 15 / 40 / 120 / 300 / 800 / 2,000 Gems (x5 = 5x), same unlock gates as the base tier. Paid random items: the shop's Gems switch is hidden and `BuyEgg` refuses them when PolicyService restricts paid random items or the check hasn't succeeded. Gems sink logged as `GemEgg_<Tier>`; funnel step `FirstGemEgg`. Harvested items carry the base tier (`item.tier`) and the egg (`item.egg`). Gem eggs survive rebirth (planted ones go back to the bag).
- **Limited eggs** (`Config/LimitedEggs.lua`; adding one = a config entry + its species in `Config/Mutants.lua`, bucket = its id, also listed in `tools/gen-mutants.luau`): tiers generated in `Eggs.lua` outside `Eggs.order` (`Eggs.limitedOrder`), Gem-priced, no unlock gate, values/sizes of their `valueTier`, odds from `rarityFrom` x `rarityBoost` (the Gem-egg construction). On sale only while `startsAt <= now <= endsAt` (`ShopRules.activeLimited/isLimitedActive`; BuyEgg refuses "ended"). Paid random items: hidden and refused when restricted. After the window owned eggs still plant/hatch; planted ones survive rebirth like Gem eggs. Sink `LimitedEgg_<id>`, funnel `FirstLimitedEgg`. While one is on sale at server start, World puts its `banner` on the Egg Shop roof sign and its `decor` around the fountain. **Pumpkin Egg** (Halloween 2026): 600 Gems (x5 3,000), 30 min, Lab values (11K), Lab's Uncommon+ x2 renormalized (53.8 / 30.8 / 12.3 / 2.9 / 0.15%), design `jack`, 10 species (2 per rarity), 2026-10-29 00:00 EDT to 2026-11-05 23:59 EST = unix 1793246400..1793941140.

- Rarity value x1 / x3 / x10 / x40 / x250; grow time x1 / x1.25 / x1.5 / x2 / x3. Rarity is rolled **at planting**, revealed at harvest.
- Luck multiplies Uncommon+ weights, then renormalizes to 100%. Total luck capped at 6x.
- Mutations: exactly 10 rolls per grow, spaced evenly through growth; each roll checks each mutation independently. Shiny x2 @1.5%, Golden x5 @0.6%, Radioactive x10 @0.25%, Glitched x25 @0.08%, Cosmic x100 @0.01% per roll. Multiplicative, each at most once (ceiling x250,000). Offline rolls stop 2h after leaving unless Offline Mutations is owned.
- Size bands: 0.8–1.0 (25%), 1.0–1.3 (55%), 1.3–2.0 (17%), 2.0–2.9 (2.5%), 3.0 Titan (0.5%); luck boosts the top two.
- Value = base x rarity x mutations x size x cash multiplier. Cash multiplier = (1 + 0.5 x rebirths) x (1.5 if VIP) x (1.1 if in the group).
- **Watering** (2026-11-03; `Config/Game.water`, rules `shared/Watering.lua`, math `shared/Growth.lua`, server `WaterService`): the whole plot grows **2x while its owner stands on the water pad** (a blue pad with a sprinkler by the gate; `PlotService` checks the owner's HumanoidRootPart against the pad's `Radius` + 0.5 every 0.25 s and calls `WaterService.setOnPad`, which settles first). The HUD's **growth circle** offers a boost the server rolled (`waterOffer`: 3x 30%, 4x 22%, 5x 16%, 6x 11%, 7x 8%, 8x 6%, 9x 4%, 10x 3%; 4.94x average); `TapBoost()` sets the plot to it for **5 s** (`wateredUntil` / `waterMult`; refused until the last boost ends, 0.3 s early is fine), rolls the next offer and counts `stats.waters`. The pad and the boost don't multiply (the higher applies); both stack with the 2x Growth Speed pass and the upgrade. Nothing runs offline (the boost ends and `onPad` clears at release). Rebirth ends the boost.
- Farm income (`DataService.incomePerMinute`, in every snapshot, on the Cash panel and the gate): **the pen's income only** (what its mutants earn per minute; eggs earn nothing until they're hatched and sold), cents kept. Text (`shared/GateSign`): "$3.4K/min", cents under $10 ("$0.04/min": one Starter Common in the pen); with nothing growing it adds "· HATCH EGGS" (some ready) or "· PLANT EGGS". The snapshot carries `growingCount` / `readyCount` and is re-sent the tick an egg matures.
- Upgrades: slots 7–40 from 200 Cash, x1.5 each; Growth Speed and Mutation Odds 5 levels, +10%/level, from 2,000, x3 each. All upgrade costs x(1 + 0.5 x rebirths).
- **Gem upgrades** (`Config/Upgrades.gem`, rules in `shared/GemUpgrades.lua`, intent `BuyGemUpgrade(kind)`, `profile.gemUpgrades`, kept through rebirth, not random so not policy-gated, sink `GemUpgrade_<kind>`): **Pen Slots** +4 pen mutants (`DataService.penCapacity`, also the pin cap) for 150 Gems, once per rebirth level (level <= rebirths + 1); **Permanent Luck** +10%/level (added to the Almanac's, under the 6x cap), 3 levels 200 / 400 / 800; **Offline Mutations** +2 h of offline rolls/level, 3 levels 100 / 200 / 400 (MAX with the pass).
- Rebirth costs: Rebirth 1 = **700K**, each next **x4.5** (3.15M, 14.2M, 63.8M, ...): `Rebirths.firstCost x costGrowth ^ rebirths`. Pacing is tuned with this, not egg prices (Lab stays 5K to keep the 50 -> 500 -> 5,000 ladder). Sim (60 runs, 1.5 active h/day, 2026-11-01): first rebirth 25 sim-min (~33-40 real min, the 35-45 target); free Rebirth 4 day 3, Rebirth 10 day 23; paying (2x Luck) Rebirth 4 day 2, Rebirth 10 day 14; paying + Auto-Harvest (`--autoharvest`: toggles on, Commons sold, 8 h offline) Rebirth 4 day 2, Rebirth 10 day 12. Rebirth (`RebirthService`) first **sells the bag at full value** through `EconomyService.sellItem` (logged, counted in `totalCashEarned`) except the pen's mutants (pinned ones always stay), then resets cash (to `startingCash`, so that Cash goes too), bought slots, upgrades, eggs (back to the starter eggs) and growing plants; keeps pen, passes, gems, Almanac, streak. Step on the **Rebirth Altar** (south edge of the plaza) to open the panel; its sign shows your next rebirth, cost, what it unlocks and a Cash/cost bar.
- Slots: `slotCount` is **bought** slots; `DataService.totalSlots` adds 10 for the PlotSlots10 pass (max 40) and is what plots/validation use. The next patch is priced by bought count (`DataService.nextSlotCost`).
- Weather (`WeatherService`, `Config/Weather.lua`, `shared/Weather.lua`, `shared/WeatherRules.lua`): a **global schedule**, a pure function of wall-clock time so every server runs the same events at the same moments: 1500 s buckets counted from the unix epoch (on the hour every 5 h), each bucket's event starts 300 s in, its type a seeded hash of the bucket index weighted Acid Rain 45 / Solar Flare 40 / Glitch Storm 15. Each lasts **120 s**; every growing egg rolls the event's `chancePerRoll` (x luck, capped at 0.9) at the start and every 30 s (4 rolls): Acid Rain 25% (Radioactive), Solar Flare 30% (Golden), Glitch Storm 10% (Glitched), ~68 / 76 / 34% per egg over a full event. A chance per tick, not a forced roll. HUD: the weather line centered under the Cash / Gems row in every zone: plain text with the event's glyph ("SOLAR FLARE IN 9:24"), a chip in the event's color from 5 min before ("... IN 4:12") until it ends ("SOLAR FLARE · 1:42 LEFT"). Replicated as Workspace attributes `WeatherNextId/NextAt/Id/EndsAt`. Announced in each server (`WeatherAnnounce`): a toast at T-5:00 (plus a TextChatService system line), T-1:00 and the start. **Discord** (Glitch Storm only, at T-5:00): one server per event claims its start time in the MemoryStore sorted map `WeatherAnnounce` (UpdateAsync, 3600 s) and POSTs `{event, startsAt, link}` to `Game.relayUrl` with the secret `WEATHER_RELAY_KEY` in the `X-Relay-Key` header (Roblox secrets can't go in a body); `relayUrl` "" / no secret / no HTTP = skipped, logged once. Relay setup (Discord webhook, Cloudflare Worker + KV `POSTED`, secrets, Roblox secret + Allow HTTP Requests, `relayUrl`/`gameLink`): `tools/relay/README.md`.
- Monetization (`Config/Passes.lua`, `Config/Products.lua`, **every pass and product is linked to its Creator Hub id (2026-11-02)**; the in-game R$ buttons read `price` from the config, so a price changed in Creator Hub must change there too; Studio's output lists any id set back to 0 on startup): passes Luck2x, AutoHarvest (see **Auto-Harvest** below), GrowthSpeed2x, OfflineMutations, PlotSlots10, VIP (gold `[VIP]` chat tag from the `VIP` player attribute, 1.5x Cash, **50 Gems/day** claimed from the Daily panel's VIP strip; the VIP egg is M5); Gem packs; Starter Bundle (offer window 10 min from first join, once). Every Robux purchase fires `PurchaseFx` to the whole server: a sparkle burst on the buyer's plot, and for VIP / the bundle a system chat line ("X just went VIP!").
- **Auto-Harvest** (pass; `GrowthService.autoHarvest` every growth tick, also on an empty plot; rules in `shared/AutoHarvest.lua`): every mature egg is hatched with a toast (no cutscene). One of `Game.autoSellRarity` (Common) is sold at once through `EconomyService.sellItem` (logged, counted in `totalCashEarned`, needs no bag room, never a pinned item; one "Auto-sold N Commons for $X" toast per pass); the rest go to the bag, or wait mature on their patch while it's full. **Replant toggle per patch** (`SetReplant(slotIndex, on)`, 0 = every owned patch; needs the pass; default off): on, the empty patch plants its last egg again, from the bag first, else bought with Cash at the shop price; Gem and limited eggs are never bought (bag only); a patch that can't replant stays empty and retries every tick. Off: harvested and left empty. Harvesting by hand turns that patch's toggle off; planting by hand never changes it; rebirth keeps toggles on the patches still owned. **Offline** (`catchUp`): `AutoHarvest.run` replays a pass when you left and at every later maturity of a still-growing egg, for at most `Game.autoHarvestOfflineHours` (8); mutation rolls under the usual offline cap; Welcome back lists Commons sold for $X, kept, patches waiting for Cash or eggs, eggs waiting for bag room, and "works the first 8 hours". No egg is bought with Cash anywhere else.
- Pen: the `penDisplayCount` = 8 mutants in the pen are the **pinned** ones (`Pin` intent, Sell panel row toggle or the hatch reveal; capped at 8; Sell All skips them; kept on rebirth), then the most valuable of the rest (`shared/Pen.lua`). Pen income: each pays **0.05%/min** of base value (tier x rarity only) x the **rebirth multiplier** (not VIP/group) online, every 60 s (`IncomeService`, fractions carry), and **0.01%/min** offline for the whole time away, no cap (paid at join, shown on Welcome back). A plain mutant pays back its sell value in ~33 h online. HUD: coin bar fills toward the next payout; chip shows $/min and the countdown.
- Gem sinks: **Luck Potion** 25 Gems, 3x luck for 30 min (stacks time; x the 2x pass, capped at 6x), sold in the Shop and on the hatch reveal; **Skip Timer** 5 Gems per started 10 min left on each egg (**soft-launch tuning flag**: if Skip revenue is high while day-3 return is low, it's eating the timers that bring people back; reprice on total remaining minutes), finishes every growing egg (the skipped mutation rolls still happen), badge on the egg tray when the longest wait is 2+ min. **Instant Weather** 400 Gems (`BuyInstantWeather`): a 120 s event of your choice on your plot only, same roll mechanics as global weather (independent of it), never two at once, policy-gated like the potion, sink `InstantWeather_<id>`; pink HUD button (only when no global event runs or starts within 5 min and none of yours runs) -> picker panel, also in the Shop's Gems section; rain + cloud over that island (player attributes `PlotWeatherId/EndsAt`). **Rebirth Now** 100 Gems (`RebirthNow`): from 50% of the next rebirth's cost, the exact rebirth flow then the Gems (checked first); sink `RebirthNow`; not policy-gated; pink button beside the bar in the Rebirth panel and on the Altar sign while 50% <= Cash < cost.
- **PolicyService:** `MonetizationService` checks `ArePaidRandomItemsRestricted` on join (failure or unknown = restricted, `snapshot.paidRandomRestricted`). Restricted players see no Gems switch in the Egg Shop and no Luck Potion, and the server refuses Gem eggs and potions (`ShopRules.canBuy` / `canBuyPotion`).
- Cash upgrades (`BuyUpgrade`, Upgrades panel, ⬆️ icon with a red dot when affordable): Growth Speed / Mutation Odds, 5 levels, reset on rebirth.
- Group (`Game.groupId`, 0 = off; `GroupRewardService`): members get **+10% Cash permanently** (`groupCashBonus`, part of the cash multiplier) while they're in the group: checked on every join with `Player:IsInGroup`; offered once after the first sale ("Join the group for +10% Cash forever (+2 Swamp Eggs now)", `GroupOfferPanel` -> Roblox's join prompt -> `ClaimGroupReward`, also in the Daily panel); a non-member's sales re-check with `GetGroupsAsync` (at most every 30 s) so joining mid-session pays on the next sell. Badge beside the Cash panel. The 2 Swamp eggs are a one-time extra.
- Almanac milestones (`Game.almanacMilestones`, `profile.almanacRewards`): every 25 species pays 25 Gems, except the big ones: a Toxic egg at 100, a Void egg at 200, a Cosmic egg at 300, **+10% luck forever** at 400 (`profile.almanacLuck`) and **100 Gems** at 500 (510 species with the Pumpkin's). The Almanac title shows the next one. Cosmetic egg skins are v1.5 (no cosmetics in v1).
- Leaderboards (`LeaderboardService`): `leaderstats` Rebirths + Cash in the player list; two global boards side by side at the north edge of the plaza, **Top Pens** (pen value at x1, `TopPens_v1`) and **Top Rebirths** (`TopRebirths_v1`), top 100 each, saved every 120 s and on leave and sent to clients (`Leaderboards` remote); `LeaderboardController` draws them as scrolling SurfaceGuis with your own rank at the bottom (`#100+` outside the top 100: OrderedDataStore has no cheap rank lookup).
- Analytics funnel: Joined, FirstPlant, FirstHarvest, FirstSell, FirstRebirth, FirstPurchasePrompt (logged when any purchase prompt closes, bought or not). Every Cash and Gems source/sink goes through `EconomyService` and is logged.
- Inventory cap 200. New player: 100 Cash + 2 Starter eggs.

## Mutants, eggs and how big things look

- **500 species** in `Config/Mutants.lua` (83 per egg tier: 26 Common / 20 Uncommon / 16 Rare / 13 Epic / 8 Legendary, +1 Common for Starter and Swamp) plus the limited eggs' hand-made species (Pumpkin's 10): `species[id]` (looks) and `buckets[tier][rarity]` (ids, `Tier_Rarity_NN`; every old id still exists). Rarity and species are rolled at planting; species is cosmetic (value = tier x rarity x mutations x size). `tools/gen-mutants.luau` regenerates the roster from `Config/MutantStyle.lua` and **overwrites hand edits**; it asserts nothing is shared between tiers.
- **Each tier reads as its egg** (`Config/MutantStyle.lua`, part recipes MutantModel builds): its own bodies, skin, eyes, signatures, feature pool, props, names and idle, no list shared between tiers. Starter: blob / puff / pear, SmoothPlastic pastels, sprout / single antenna / baby eyes / leaf hat / rosy cheeks, idle bob. Swamp: flat / toad / lumpy with webbed feet, mossy greens under a Glass wet sheen, gold frog eyes, lily pad hat / reeds / frog mouth / dripping algae / bubbles, idle sag. Lab: tall / capsule, the only tier with arms, pale SmoothPlastic, glass dome / goggles / neck bolts / clipboard / body vials, idle twitch. Toxic: spiky / lopsided / melted, slime Glass (reflective) in acid greens with a faint haze, dark eyes with an acid-green slit, hazard stripes / leaking barrel / third or fourth eye / melted side / fumes, idle drip. Void: wisp / long / adrift (a floating head) / ring, matte black-purple with dark trails, hollow eyes, one glowing white eye / floating ring / body tears / shadow trail, no feet, idle hover + flicker. Cosmic: crystal / prism / orb cluster, Foil with Neon star specks, pale starlit eyes, satellites / halo / ring crown / nebula, idle orbit. Neon only on specks, eyes and sparks (tests check no Neon part is over 0.5 x the mutant's scale).
- **Rarity is a feature budget** (`MutantStyle.budget`): Common 1 feature (its signature), Uncommon 2, Rare 3, Epic 4 + a prop no other species in its tier has, Legendary 5 + a unique prop + a named idle variant ("Happy Hop", "Grand Orbit", ...) + 1.2x base scale. One feature per slot (no two hats). ## Art rules

- **No Neon on large surfaces, no strong lights.** Neon only for small details (crack lines, star specks, tiny jewels). PointLights on mutants: range <= 16, brightness <= 0.35. Bloom stays near-invisible (intensity 0.12, threshold 2.6). Players complained the old glow hurt their eyes.
- Labels are SurfaceGuis on physical signs, not floating BillboardGuis. Temporary billboards (timers on your own plot) only. Sign text goes on the board's **Front** face (the face pointing toward whoever reads it); the preview renders SurfaceGui text so you can check it isn't mirrored.
